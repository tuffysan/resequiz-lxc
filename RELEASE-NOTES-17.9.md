# Resequiz 18.0.0 — Automatic Category Discovery

Admin kan nu välja en kategori och låta Resequiz automatiskt söka igenom flera relevanta ämnesområden i Wikidata. Resultaten dedupliceras mot både befintliga frågeformuleringar och factKey. Kandidater sparas aldrig automatiskt: admin öppnar källan, granskar och använder kandidaten som utkast innan den sparas som verifierad fråga.

Funktionen stöder svenska, engelska, tyska och spanska som källspråk och 20/40/60/80 kandidater per körning.
