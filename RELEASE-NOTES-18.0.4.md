# Resequiz 18.0.4

## Mobile UX overhaul
- Phone layout now uses the full viewport instead of a desktop card scaled down.
- Larger headings, body text, form controls and touch targets.
- Main home actions are full-width and easier to use one-handed.
- Home screen fills the visible phone height and removes the desktop footer on phones.
- Online lobby, join flow, questions, answers, result cards and QR layout are enlarged for phones.
- Updated frontend cache key to `1804-mobile2`.
- Includes the 18.0.2/18.0.3 new-game state fixes.
