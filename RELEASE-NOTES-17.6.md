# Resequiz 17.6 – Themes & Languages

- Global theme selector available in every UI variant/view.
- Themes: Original Dark, Midnight Blue, Light, Sunset and Forest.
- Languages: Swedish, English, German and Spanish.
- Selection persists locally and applies across Home, Online, Offline, TV Display, Remote, Quizmaster, Studio, History, Leagues, Statistics, Admin and Install views.
- Dynamic UI content is translated through the shared UI translation layer.
- Category names and common game controls are localized.
- Existing dark theme remains the default.
- Quiz question facts/content are preserved unchanged to avoid machine-generated mistranslations of the verified question bank; the language setting localizes the application UI.
