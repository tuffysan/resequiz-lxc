# Resequiz 16.7 — Massive Verified Expansion

16.7 expands every category except **Världen** and **Hjärngympa** without introducing unverified facts.

- 600 additional verified question formulations (40 per eligible category).
- 9,359 active questions total.
- Världen remains 2,255 and Hjärngympa remains 4,937.
- Each new formulation inherits the source-backed fact verification from its 16.6 base question.
- New variants deliberately keep the same `factKey` and `family`, so Smart Repeat treats them as the same underlying fact and avoids repetition in a game night.
- This release increases formulation variety; it does **not** falsely claim 600 new independently sourced facts.
