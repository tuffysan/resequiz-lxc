# Resequiz 12.1 – Question Quality Overhaul

12.1 is a content-quality release. No new gameplay feature is the headline; the question bank itself has been made substantially cleaner.

## Bank changes

- 13,002 -> 10,614 questions.
- 2,388 weak, redundant or mechanical questions removed.
- v7.2 paired/template expansion removed because it contained inconsistent semantic distractors and duplicated facts.
- Repetitive v7.5 arithmetic/conversion series removed.
- Repeated v7.5 audio questions removed; the 48 unique local audio questions remain.
- High-value visual and factual expansion questions retained.
- Duplicate Sweden expansion prompts removed in favour of the existing core versions.
- Duplicate Reykjavík and chemistry-trivia items removed.
- Image prompt wording cleaned up.
- H2O wording/explanation improved.

## Validation

- 10,614 unique question IDs.
- 0 malformed questions.
- 0 duplicate answer options.
- 0 templated-question warnings in the structural audit.
- 0 semantic audit issues under the current rules.
- 730 visual questions.
- 48 audio questions.
- 0 missing referenced media files.

The lower question count is deliberate. Future additions should only be accepted when the wording is natural, the fact is defensible, distractors are plausible and the question adds real variety.
